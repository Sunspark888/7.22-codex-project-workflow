# PMR 公开站维护标准 · 2026-10-13

本文件仅适用于公开产品展示站（非私有科研记忆库）。

## 定位

PMR = 专注大项目治理。展示项目连续性、科研/产品决策记忆、证据检索与可读图鉴。公开网站作为作品与概念演示，不代表记忆引擎完整商业化或已在任何用户环境自动部署。

## 设计标准

1. 延续克制的灰白与森林绿色、移动端适配、可读中文；不随维护模型随机更换视觉风格。
2. 首页提供产品问题、价值、工作方式、设计原则和独立演示入口。
3. 演示围绕“项目现状→研究历程→实验对比→决策理由→待议事项”组织。
4. 所有演示数字、人物及项目均明确标注为虚构，不冒充实际模型性能或研究结果。
5. 保留键盘可达、可辨的链接与交互；更新后至少检查桌面、手机、五个演示分区与浏览器脚本错误。

## 公开边界

- 不上传任何真实项目 L1–L4、聊天原文、未发表论文/实验、内部知识卡、Drive 私有链接、账号凭据。
- 私有 PMR L2H 的工作副本与公开产品站分仓维护；仅由人审定后提炼可以公开的故事。
- 用户要求更新私有研究图鉴时，不修改公开站；用户要求更新公开站时，不覆盖私有 V5.1 与 Skill。
- 页面不得收集访客输入或向第三方发送数据；新增分析工具或表单必须明确告知。

## 技术

纯静态 HTML/CSS/JS，无依赖、无后端。首页与演示相互链接。发布分支 `gh-pages` 与工程主分支隔离。仓库拥有者可将同一站点部署到 Vercel 或 GitHub Pages。

## 后续版本

仅在界面、交互、公开内容实际变化且经过检查时发布。保留上一版 Git 提交，可回滚。不以没有验证的检索实验数据作为营销宣称。
