REAL FAILURES

两次实测
暴露的关键误区

坑 1：把 /root 当成项目主线程

/root 只表示当前线程内部的根 Agent。项目角色必须来自明确任命或任务卡。

坑 2：把任务卡当成新线程

创建 task card、claim，甚至模拟一句 Worker 问候，都不代表真正创建了线程。

再加一条验收边界

Worker 说“完成”只是 delivered；只有主线程验证后，任务才是 accepted。

协议要能防止“假完成”06 / 07
