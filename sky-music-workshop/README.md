# 🌿 云间琴房 · Sky Music Workshop

**你也可以成为自己发抖音作品的练琴大师！**

从第一张电子谱，到第一支演奏作品，云间琴房陪你慢慢完成。

少一点抄谱和剪片，多一点弹琴的快乐。

给喜欢在光遇里弹琴的你，一套从整理琴谱到分享演奏的 AI Skills。

这件事的起点很简单：我以前会自己手写琴谱。抄一首要花很久，写完手也累了。后来想，能不能把这些重复的工作交给工具，让手机、平板和电脑都成为自己的小谱架？

于是，我们把反复使用的排谱与视频制作方法，整理成了「云间琴房」。它包含两个可以分别使用、也可以接着用的部分：**琴谱整理**与**演奏视频剪辑**。默认沿用我们自己练琴时的样式，也欢迎你选喜欢的尺寸和封面，或继续二次开发。

## 🎹 第一部分：让看谱轻松一点

不是每次练琴，都要先辛苦抄一遍谱。

| 练琴时遇到的麻烦 | 我们怎么处理 | 你能拿到什么 |
| --- | --- | --- |
| 手写琴谱费时，写久了很累 | 将已有数字谱截图转录、复核，再按统一规则生成电子谱 | 手机、平板和电脑可以打开的高清图片 |
| 设备屏幕大小和比例不同 | 支持自选琴谱输出尺寸；默认每页三行，**单页最多三行** | 单页演奏谱、四页收藏拼图和总谱 |
| 喜欢的封面各不相同 | 支持选择封面尺寸、配色与摄影、清新、插画、极简等风格 | 与自己的审美、曲子情绪相配的封面 |
| 不同来源排法不同，同一音区有时在上、有时在下，新手要反复找 | 统一十五键音区位置、同时音对齐和节奏间距，固定三排琴键的阅读映射 | 换一首曲子，也能沿用熟悉的看谱方式 |

这里说的“三行”是**每张单页最多三条谱面行**；每条谱面内部还会按固定音区摆放音符，两者不是同一个概念。四页拼图与总谱用于收藏总览，不代替单页跟弹。

你可以直接说：

> 帮我把这些截图做成光遇十五键琴谱。用默认规则，每页最多三行，琴谱尺寸选1920×1080，封面想要清新的浅绿色。

不选也没关系，我们已有一套默认值：2160×1080单页、每页三行、浅色谱面、2048×2048封面。变更尺寸采用等比适配，比例不同时保留留白，当前不会自动重新排成竖版音符布局。屏幕上的实际大小仍取决于打开方式与设备。

## 🎬 第二部分：弹错了，停一下，再来就好

录到一半按错一个键，不必因此把整首推倒重来。

**可以继续录着，停一下，从刚才的完整乐句重新弹。** 把这份录屏和琴谱交给 GPT，让它结合谱面与演奏核对重弹位置，保留合适的片段，再执行剪辑。一个原视频就可以开始，不要求你先切成许多小视频；已经有单独补录，也可以一起提供。

| 以前要自己忙的事 | 云间琴房的工作流 | 最后交付 |
| --- | --- | --- |
| 找错弹位置、找后面重弹的片段、来回剪接 | AI分析并核对保留片段，脚本按剪辑清单执行，检查接点 | 连贯的演奏视频，保留原演奏声音 |
| 剪完还要摆琴谱、摆录屏、对翻页 | 按剪后时间重新同步琴谱和演奏 | 左边琴谱、右上封面、右下真实演奏的横屏成片 |
| 看跟弹视频时容易跟丢位置 | 彩色竖线＋顶部小倒三角，跟随已核对的演奏锚点移动 | 有位置提示的跟弹视频，颜色可自选，默认珊瑚红 |
| 视频做好了，还要另做宣传图、想标题和正文 | 同一作品统一视觉与语气，按平台整理发布素材 | 小红书、抖音、快手、视频号封面，以及标题、正文、标签、置顶评论草稿 |

你可以这样交任务：

> 这是我的琴谱和原录屏。我弹错后停了一下，后面重新弹了，请保留正确的重弹片段。按默认布局做成带彩色游标的跟弹视频，再给我四平台封面、标题、正文、标签和置顶评论。封面想要温柔一点的云海风格。

从使用者的角度，是**交一次素材，接收一套发布包**。分析、剪辑、同步、合成与检查由执行代理接着做，遇到无法确定且影响结果的片段，才指出具体疑点。它不要求你自己操作剪辑时间线，也不等于上传后立刻完成。

### 关于“自动纠正”，说清楚一点

纠正指的是**用你实际重弹正确的片段替换错弹片段**，不会凭空生成你没弹过的正确演奏。停顿只是定位线索，不能把所有静音、自然休止和歌曲反复一律删除。

当前工具由“AI核对素材＋确定性脚本执行”组成。渲染脚本本身不自动识别错音，也不自动生成逐音同步锚点。执行环境需要能够查看、分析音视频；无法可靠判断时，需要提供明确时间点或补录。交付发布包后，由你选择发布，工具不会擅自登录或代发。

## 安装与开始

这是两个带脚本、规则与示例的 Skill，不是独立手机 App。需要一个能读取素材、运行本地程序的 AI 代理环境。

```bash
git clone https://github.com/Sunspark888/7.22-codex-project-workflow.git
cd 7.22-codex-project-workflow/sky-music-workshop
```

将 `skills/sky-15-key-score` 和 `skills/sky-score-social-video` 两个完整目录放到代理使用的 Skills 目录；只需排谱时可以只装第一个。Codex可放到 `~/.codex/skills/`。随后按各部分说明安装运行依赖。

- [琴谱：安装、演示、自选尺寸与实际测试记录](docs/sky-15-key-score.md)
- [视频：依赖、录屏建议、执行流程与交付边界](docs/video.md)
- [琴谱 Skill](skills/sky-15-key-score/SKILL.md)
- [视频 Skill](skills/sky-score-social-video/SKILL.md)

## 换个模型，也尽量少走弯路

我们将可以固定的规则写进脚本，把输入清单、出错条件、来源复核与交付检查写进规范，让新会话不用翻旧聊天才能继续做。

琴谱模块已通过24项测试；GPT-6 Luna / Low在无历史上下文的新会话中完成过默认与自选外观的合成示例制作。这验证了配置和生成流程，**不代表弱模型能准确识别所有模糊截图，也不代表视频错音识别经过同等测试**。详细范围见使用说明。

欢迎二次开发：改变外观、扩展设备适配、增加自己的样式。默认单页最多三行，避免为了少翻页把数字挤得太小；如需更多行，请作为明确的自定义扩展，重新检查实际屏幕可读性。
