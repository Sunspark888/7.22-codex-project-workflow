# 光遇十五键琴谱整理规则 v1.12

本规则把已确认的紧凑音块版数值完整写出，不依赖外部黄金样图。歌曲之间可以改变封面、背景、配色与字体气质，但数字、附点、快速横线、层距和时间槽的视觉语法固定不变。以下固定尺寸、颜色及封面摄影偏好均为默认基准。用户显式选择 presentation 时，由 customization.md 覆盖外观相关条款；音符与时间约束始终生效。

## 1. 目标优先级

1. 数字、附点、同时关系、快速横线和页序绝对准确。
2. 时间关系无需猜测即可读懂。
3. 手机横屏清晰、利索、易演奏。
4. 背景好看但不干扰阅读。
5. 交付完整，直接显示图片，不用 ZIP。

## 2. 默认交付物

每首歌默认必须交付：

1. 一张 1:1 方形封面；
2. 每个谱面页面的独立横屏 PNG；
3. 每四页组成一张 2×2 合成图；每页三条谱面行，通常每张合成图共 12 行；
4. 包含全部页面的完整总谱 PNG。

默认不制作“两页拼一张”。仅在用户明确要求时增加，不得用双页图替代单页、四页合成或完整总谱。

新作品的所有图片在同一条回复中按“封面 → 单页 → 四页合成 → 完整总谱”逐张展示。局部修订展示修正页及更新的合成／总谱，用户要求全部图片时逐张给全。禁止默认发送 ZIP。

## 3. 封面

- 默认1:1、2048×2048；用户可通过 presentation.cover 选择其他尺寸。
- 优先选用真实风景摄影：先检查用户提供的实拍素材，再查找与歌曲意境相符、清晰度和构图适合的真实照片；找不到合适且可用的照片时，再自行生成照片级写实风景。默认不采用动画、动漫、卡通或绘本风；用户选择 illustration/fresh/custom 时按其风格制作。
- 使用外部照片前核实原始来源、作者（可得时）、许可或使用条件是否适合本次用途，并在素材记录中保留来源链接与授权依据。搜索结果、热门图片或“网上可见”本身不代表可用；不可核实或要求与无水印、无无关文字的封面不兼容时换图或生成。生成素材标明为生成，不把它描述成真实拍摄。
- 选景前必须参考歌词、歌曲主旨，以及该曲在网络上的热门相关图片和常见视觉意象；用于确定情绪、地点、季节、时间和色彩方向，不得直接照搬受版权保护的构图。
- 标题必须准确；按每首歌的情绪选择自然、有表现力的字体，可用舒展手写、书法感或有编辑设计感的字体，避免刻板、办公文档式字形与机械套用同一字体。先确定底图，再用确定性文字排版；创意字形不要求交给生成模型绘字。
- 把标题当作画面构图的一部分：根据主体、留白、光线和色彩设计位置、大小、字距、层次及必要的遮挡关系，使文字自然融入风景，并最终合成为同一张封面 PNG；不得只在图片外加标题，也不得默认用大块白卡片或生硬标签盖在照片上。融合不能牺牲标题完整性和缩略图可读性。
- 随附封面脚本的固定布局只作起点；若无法形成适合当前照片的融合效果，使用等价的 SVG/Canvas 等确定性排版或合成实现，不机械沿用内置卡片与固定坐标。
- 《Dehors》这类重意境、浪漫或自由感的歌曲，封面标题使用贴合歌曲气质的艺术字，例如轻盈舒展的手写体或书法感字体。清单用 `cover_title_font_file` 单独指定标题字体；副标题与起始音继续使用清晰字体。艺术字只用于标题，不改变谱面数字、附点、横线和行距的黄金模板。
- 验收实际渲染出的标题字形、与画面的融合效果及手机缩略图可读性，不能只确认已指定字体文件；若字体回退为普通字体、字形缺失、被遮挡或裁切，修正后再交付。
- 原谱或用户明确提供起始音/定调时才标注，例如 `A = E♭`；没有提供时直接省略，不得套用默认值或猜测。
- 封面色调不设“必须浅色”的限制；根据歌曲气质选择明亮、深色、活泼或压抑风格。
- 避免与上一首歌模板化雷同。
- 不得包含水印、账号、平台 UI 或无关文字。

## 4. 谱面画布与背景

- 默认单页为 2160×1080 横屏（自选尺寸按基准等比适配）；这是 2×2 合成后形成 4320×2160（2:1）手机横屏图的基准画布。
- 每张标准单页固定三条谱面行，最后一页可少于三条；四页合成通常共 12 条谱面行。
- 转录完成后必须把全部谱面行按原顺序展平，再每三行连续分页并重新编号。来源截图的分页只用于追溯，不能决定输出分页。
- 不得缩小字号、压扁行距或硬塞第四行；第四行及后续内容顺延到下一页。该顺延产生的新页同样参与四页合成和完整总谱。
- 默认内容左右边界约为 `x=120` 与 `x=2040`，保留舒适页边距。
- 谱面背景必须是浅色系；可使用天空、晨光、云、草地、花朵、纸张等低对比背景。
- 同一首歌使用 1–2 张统一风格背景。偏好约为：70% 浅蓝—浅粉天空/晨光，30% 春日自然背景。
- 数字区可覆浅色半透明卡片，但背景仍应可见；不得接近黑底，也不得让背景影响数字、附点和线条。
- 页面上下应适当拉长，谱面行之间保持呼吸感。

## 5. 十五键映射

| 谱面行 | 按键 |
| --- | --- |
| 第一行 | 1、2、3、4、5 |
| 第二行 | 6、7、1̇、2̇、3̇ |
| 第三行 | 4̇、5̇、6̇、7̇、1̈ |

- 对原谱左右两部分全部应用映射。
- 只改变纵向行位，不改变事件先后、同时关系和横向时间结构。
- 同一时刻的音共享同一个横向坐标；跨行同时音必须上下严格对齐。

## 6. 同时音与紧凑音块

- 同次按键、同一行出现多个数字时，直接写在一起，不加 `+`、括号、外框、顶线或颜色。
- 所有数字高度和字号完全一致；不能通过缩小多音组合来区分。
- 多数字组合只压缩横向字距，形成明显紧凑的音块，例如 `1+4+5 → 145`。
- 紧凑音块内相邻数字采用固定中心距 `0.50em`；三行页 54 px 字号下为 27 px。必须逐字定位，不能依赖字体默认字距。
- 单个数字不压缩；快速连续的多个独立事件仍按时间单位分别占位。
- 同一行内部按琴键顺序排列；跨行组合分别放在对应行并共用 x 坐标。
- 当多行/多音事件与相邻 `1×` 快速事件相连时，采用 C 方案光学间距：左事件最多左移 7 px、右事件最多右移 7 px，使两事件的视觉边界最多增加 14 px。调整必须受当前小节边界和相邻事件约束；不得跨越分隔线、改变事件顺序，或破坏 `2×/3×` 的整体时间比例。
- 同一快速链连续出现多个高密度事件时，共享事件的修正可以相互抵消；优先保证所有事件中心仍服从原时间槽，只做局部防粘连，不累积扩张整条快速链。

视觉语法只有两项：

- 紧凑音块：同一次按键中的多个同排音；
- 下方横线：多个事件连续快速弹奏。

不得再添加合音框、左右括号、顶括线等额外符号。

## 7. 数字、附点与颜色

- 全谱使用《Leave Me Alone》固定视觉规格。除非用户明确改变模板，不得凭观感另定字号、笔画或标点大小：

| 元素 | 固定基准 |
| --- | --- |
| 三行页数字 | DejaVu Sans，54 px，字重 720，颜色 `#111820` |
| 一／二行尾页数字 | 同字体 54 px；稀疏尾页也不改变字号 |
| 三层行距 | 固定 82 px |
| 单附点 | 半径 3.7 px，水平居中于所属数字 |
| 双附点 | 两点纵向间隔 9 px，逐个绘制 |
| 快速横线 | 4.5 px，圆头，颜色 `#101820` |
| 紧凑音块 | 字号不变；相邻数字中心距固定为字号的 0.50，三行页为 27 px；逐字绘制 |

- 以上数值指 2160×1080 单页的渲染规格；四页合成只是无损拼接，不得先缩小单页再拼接。
- 数字视觉标准不得随歌曲风格变化。风格差异只能作用于背景、卡片、标题、页眉与封面。
- 全谱数字使用黑色或接近黑色的深色。
- 不区分主旋律色、和弦色、左右手色。
- 单附点、双附点逐个保留，并跟随对应数字移动。
- 附点不得漏、补、错配；不得使用生成模型重画谱面。
- 下一层数字上方的附点必须与上一层数字之间保留清晰空白，绝不能接触或视觉粘连。
- 来源中的四行或更密集页面必须先展平，再顺延为每页三行；不得沿用旧版四行分页，也不得通过微调字号容纳第四行。

## 8. 时间间隔

以原谱可辨认的最小时间单位为 `1×`：

- 相邻事件可能相隔 `1×、2×、3×……`；必须根据真实位置和上下文推理，而不是只分“快/慢”。
- `1×` 连续事件形成快速组；`2×` 的横向距离是 `1×` 的两倍，`3×` 是三倍，以此类推。
- 不得把没有横线的普通音等距压成快速音，也不得把快速音拉宽成普通音。
- 防碰撞只能做最小调整，不能改变倍数关系、同时关系和先后顺序。
- 推荐每小节使用 8 个最小单位槽位；若原谱使用其他细分，以原谱为准。

## 9. 快速横线

- 下方横线只表示连续快速弹奏的多个事件。
- 横线范围以原谱为准，不能只靠数字数量判断。
- 快速组可以跨小节、分隔区、谱面行和页面；转录时必须保留连续状态。
- 跨小节时同一快速关系必须连续穿过分隔线显示，禁止仅因小节边界断线。只有原图确有较长时间间隔才断开。
- 跨谱面行/页面时，在上一行末和下一行首分别保留续接短线，不能漏掉换行后的第一个快速音。
- 续接短线必须与其所属快速段在当前行的长横线同高；高度取当前行这一整段涉及的最低层，不能只根据首音或末音定高而产生另一层悬空短线。
- 已知历史校正：快速串之后的同时音，只要仍属于原快速段，也必须带横线。
- 不能把“挤在一起”直接等同于同时音。必须先判断它们是同一 x 坐标的同按音，还是相邻 `1×` 时间槽的连续事件；后者要拆成独立事件并画横线。
- 已知强制回归：重做《Dehors》时，P3 的 `3 → 1̇ → 2̇` 是三个连续 `1×` 事件，不是紧凑同按音；前两项的 `rapid_to_next` 必须为真，成品必须出现完整横线。

## 10. 分隔线和四等分

- 原谱竖线仅为分隔线，不自动结束快速组。
- 保留原谱分隔位置和数量；不能随意增加、删除或移动。
- 每一整条谱面行从最左到最右分为四个时间区块，而不是左右两半各四分。
- 四列连续排布，中间不得人为断开。
- 辅助线应细、浅，不抢过数字和快速横线。

## 11. 禁止的视觉元素

禁止添加：

- `R1/R2/R3` 等行标签；
- 顶部十五键映射说明；
- 任意音符染色；
- 合音胶囊、圆角框、左右括号、顶括线；
- 不属于原谱的节拍编号、装饰符号或说明文字。

可保留页码、歌名、浅色四等分线、原谱分隔线、原谱快速横线和低干扰背景。

## 12. 四页合成与完整总谱

四页合成固定 2×2、按列阅读，默认成品为 4320×2160（2:1）；自选尺寸为单页宽高各乘2：

| 位置 | 页面 |
| --- | --- |
| 左上 | P1 |
| 左下 | P2 |
| 右上 | P3 |
| 右下 | P4 |

下一组为 P5/P6 在左列，P7/P8 在右列。四页比例、边界和间距必须一致。禁止把 3、5、6 个小页不规则塞进一张图；默认四格方案是字号、容量与手机横屏利用率的平衡点。

页数不足四页时仍按列填充：P1 左上、P2 左下、P3 右上；空余位置可使用封面或保持干净留白。页数超过四页时每四页生成一张合成图，并纵向组合成完整总谱。

## 13. 图片清理

- 裁掉状态栏、播放按钮、评论区、头像和平台控件。
- 去除账号水印，但不得破坏数字、附点、横线、竖线或真实节奏位置。
- 只保留琴谱所需信息；对无法安全去除且压住谱面的水印，必须指出具体位置，不得生成式猜补。

## 14. 质量检查

交付前逐项确认：

- 页面完整、顺序正确；
- 逐页确认来源谱面边界；首行、末行与稀疏收尾行都未被裁掉，页码、标题和平台文字未被吸收到最后一条谱面行；
- 所有数字、附点和同时音与来源一致；
- 逐层检查附点与上一层数字之间有清晰空白，尤其检查由密集原图顺延得到的三行页；
- 左右两部分都完成十五键映射；
- 同时音共用 x 坐标；同排多音形成紧凑音块；
- 多音事件紧接快速音时已应用 C 方案光学间距；同按音内部紧、相邻快速事件外部松，手机缩放后仍能一眼分组；
- 时间距离保持 `1×、2×、3×……`；
- 所有快速横线完整，包括跨小节、跨行和跨页；
- 每整行四列连续，中间不断开；
- 2160×1080 单页与 4320×2160 四页合成均可在手机横屏快速辨认，合成图尽量铺满屏幕；
- 三行页数字为 54 px / 720、附点半径 3.7 px、横线 4.5 px、三层行距 82 px；不得出现由来源截图分辨率造成的字号漂移；
- 除最后一页外每页恰好三条谱面行；不存在通过缩字或压缩行距容纳第四行的页面；
- 背景可见但不干扰；无水印、无多余标签、无乱染色；
- 封面已优先检查合适且可用的真实照片，外部照片来源与使用条件可追溯；生成备用图未被误称为实拍；标题字形贴合歌曲、融入画面并已合成为封面 PNG，缩略图仍清晰；
- 已生成封面、全部单页、四页合成和完整总谱；
- 未默认生成双页合成，未发送 ZIP。

验收必须分三层，不能用“看起来整齐”替代谱面事实：

1. **结构层**：每个来源数字、附点、同按关系、时间槽、分隔线与快速关系都能追溯到 manifest 事件；来源谱面行总数等于 manifest `systems` 总数，来源数字总数等于 `notes` 元素总数，来源附点总数等于音符字符串附点总数，且每个附点只归属一个数字。
2. **回归层**：用户曾指出的具体错误全部列为断言并通过；《Dehors》P3 `3 → 1̇ → 2̇` 是当前必测项。
3. **视觉层**：固定数字与标点规格通过，再检查背景、封面、页序、文件解码和手机横屏可读性。

结构层还必须执行 [source-review.md](source-review.md) 的独立复读与精确比较。总数相等不能发现错音替换、伴奏移位或高低八度互换；`verified: true` 和文字形式的“回归已通过”也不是测试证据。

针对已发生的《诀别书》问题：相似乐句必须分别读点，不能因数字轮廓相同直接复制；快速组三音的伴奏必须绑定实际对齐的第几个音，不能统一放到首音；稀疏尾声不得凭和声习惯补音。具体回归位置见来源复核规则。不得向用户保证零错误，只陈述本次实际覆盖与通过的检查。

只通过视觉层不算合格。自动识别给出“合理数字”也不算合格；若分类结果不能由原图或重复乐句确认，必须停在该局部询问。

## 15. 实现原则

谱面应以结构化事件驱动确定性渲染。优先使用 SVG/Canvas/本地脚本；Figma 可用于预览或编辑，但不是必需依赖。封面风景底图优先使用可核实来源与使用条件的真实摄影，不合适时再用照片级图像生成；标题和起始音必须后期确定性排入并融入画面，确定性排版不等于固定、刻板的封面模板。

禁止把清理后的截图、黑色连通域或 OCR 字形直接搬到新背景上当作最终谱面。该捷径会把来源分辨率带入字号、漏掉快速关系，并让相邻事件与同时音失去语义。它们只能用于候选检测和对照；最终输出必须来自结构化事件。

检测来源谱面边界时，最后一条谱面行必须由自身分隔线范围限定，不能用截图底部作为纵向终点；否则页码或平台文字可能被误识别为音符。稀疏收尾行的分隔线可能比普通行短，行检测不能只用普通行高度阈值。

PNG 必须先写入临时文件或内存缓冲区，完整解码验证后再替换正式文件。若写入截断，删除临时文件并重试；不得把能读到尺寸但无法完整解码的 PNG 交付。

## 16. 全谱时间轴与代码约束

- 先核对时间槽，再展平全谱事件，以之前所有小节的真实时长累加绝对时间；空小节也占时长，不能只按有音符的小节计数。当前标准渲染器每行四小节；非四小节输入须显式扩展几何与校验，不可静默套四列坐标。
- 在已确认的最小单位体系下，相邻事件绝对时间差为 1 时 rapid_to_next 必须为 true；差大于 1 或已是末事件则为 false。若原图不符合这一体系，先修正时间表示，不得改标志使校验勉强通过。
- 重复乐句每次出现必须有独立事件对象与来源 ID；禁止多个小节共用可变对象，禁止深拷贝整个共享对象图后误以为已消除内部引用。
- 同一行内按快速链画一条线，跨小节不拆段；换行／换页只裁分视觉段，保留音乐连接。每段高度取该段最低音层；单独一个续接音画一次短线，长线已覆盖时不再重复画端点短线。
- QA 默认聚焦本次风险，约 5–15 分钟；不做默认哈希、重复全量编码或层层审批。记录实际检查与局限，不用自填“通过”代替执行。
