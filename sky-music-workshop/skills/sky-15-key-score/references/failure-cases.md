# 历史失败 → 原因 → 固定处理

每次新增错误时，先复现或找直接证据，再更新对应代码／规则。记录确定原因与未确认假设的区别。以下为当前可见历史中的失败，不能声称覆盖未保存的所有对话。

| 失败 | 已知原因／风险 | 固定处理与检查 |
| --- | --- | --- |
| 《虚拟》P3 第一、三行跨小节断线 | 转录构造器只比较当前 measure 内下一音，末音默认 false；两份一致记录也可能共同漏连 | 全谱绝对时间独立校验；跨小节、跨行、跨页都检测 1× 关系；rapid-timeline 测试 |
| 修复重复乐句时改动互相污染、计数偏少 | 多次使用同一可变事件对象；整体 deepcopy 可保留内部共享引用 | 每个出现位置独立克隆、独立来源 ID；拒绝共享事件引用 |
| 换行端点出现悬空／重复短线 | 端点单音定高，与整个快速段最低层不一致；重复绘制端点 | 每个本行快速段只画一次，单音续接才画短线 |
| 规则已更新，执行仍用旧代码 | 同名本地副本与远程 Skill 并存；选到仅校验布尔值的旧渲染器 | 只用当前加载根目录的脚本，等价实现必须调用当前校验；项目记录规范版本 |
| 《虚拟》相似尾句漏音、点数或落点错误 | 转录事实不准确；不能仅从数量校验推断具体误读原因 | 重复段逐次读点、读时间，独立账本精确比对；不因相似直接复制 |
| 《诀别书》伴奏提前、补出不存在的音、错八度 | 按熟悉模式补和弦，复制相似乐句，伴奏错绑定到快速组首音 | source-review.md 中具体错例与可执行断言；不能只查数字总数 |
| 《Dehors》三个快音被当成同按音 | 把横向拥挤当同一时刻 | 先确定 x 时间槽；3 → 1' → 2' 为独立连续事件；紧凑音块仅用于同按 |
| 字号飘移、附点碰上一层、四行塞页 | 按源图分辨率和旧分页临时调字号 | 固定 54 px、层距 82 px；每页三行，尾页不缩字号；四拼不重采样 |
| 多音与快音粘连 | 同按块与相邻时间事件没有可辨边界 | 内部中心距 0.50em，C 方案每事件最多 7px；不得重排时间 |
| 尾声漏掉或 UI 变成音符 | 使用截图底部而非最后谱行边界裁取；稀疏行漏检 | 每行独立边界，稀疏尾声单查，账号与平台 UI 不参与识别 |
| PNG 有尺寸却损坏 | 未完整解码就把中间文件作为正式文件 | 临时写入→完整解码→原子替换；不能仅看缩略图／文件头 |
| 缺页、只交样张、遗漏合成／总谱 | 没有完整交付清单 | 从 manifest 页数枚举输出，一次交齐用户范围内全部资产 |
| 下次进程需从聊天重建工程 | 仅保存结果 PNG，素材／事件／复核依据在临时目录消失 | 持久保存项目状态、原图索引、manifest、独立账本与输出身份 |
| 封面标题刻板、字体未生效 | 固定卡片模板或字体回退，没有看实际字形 | 使用当前封面规则，标题融入构图；看实际 PNG，不能只检查配置 |

| 分享后找不到本机依赖 | 旧脚本包含环境绝对路径 | package.json固定sharp版本；npm install；runtime统一加载与清晰错误 |
| 改封面尺寸后标题裁掉 | 固定2048坐标未随画布调整 | 按实际宽高排字，真实输出尺寸回归 |
| 自定义尺寸被拉伸或单页/拼图不一致 | 各脚本各自取常量 | settings统一解析，整体等比留边，合成前检查单页尺寸 |
| 弱模型猜参数或抄旧脚本 | 多入口和未说明字段 | build单入口、完整demo、未知外观选项明确报错 |

## 维护验证

修改代码后执行一次 `node --test tests/*.test.mjs`。重点覆盖正例与历史错误负例，不扩大成不必要的全量 QA。新增规则必须说明执行入口；能编码的检查不能只留下“注意检查”一句话。
