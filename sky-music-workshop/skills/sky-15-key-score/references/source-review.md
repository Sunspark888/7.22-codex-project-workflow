# 原图复读与交付门槛

制作新谱或改错时必须执行。结构化事件只是容器，手工填错的内容会被确定性渲染器准确地画错。

## 两次读取，分开生成

1. 第一遍从原图建立时间事件，逐个绑定旋律和伴奏；保存每一行、每一个事件的来源 ID。
2. 第二遍重新看原图，独立写出每个时间位置的完整音符、音高点与快速连接，不得复制或修改第一遍数据冒充复核。若有授权的独立复核者，可只提供原图和规则，不提供旧答案或预期结论；没有时主代理分开复读。
3. 合并前逐项比较两次读取的结果。发生差异时回看具体原图区域，记录解决依据；图像仍不足则停止该局部，不以多数意见、旋律惯例或旧答案决定。
4. 单独比较看似重复的段落：数字相同、附点不同，伴奏不同，快速组内伴奏落点不同，都必须保留；不能复制首段后只抽看末音。
5. 密集组先读旋律顺序，再按原图横向中心配伴奏。伴奏可以在首音、中间音、末音或独立时刻，不能按“常见和弦”补齐。红色播放光标不是小节线或音符；遮住关键字形且无法辨认时询问。
6. 渲染前运行 `validate_source_review.mjs`。渲染后再反向核对成图（尤其相似乐句、双音高点、快速组和尾声），并确认字号、附点间隔、横线与拼图。

校验只能证明两份记录一致，不能证明两次视觉读取都无误。不得把自填总数、布尔字段或同源复制当作独立证据，也不得承诺未来绝不出错。

## 来源账本格式

`manifest.audit.source_review` 指向独立 JSON，路径相对 manifest。原图路径相对账本，必须保留；记录文件名及可得的持久文件 ID／版本，默认不计算哈希；重新取回或替换来源时重新确认受影响位置。即使重新分页，来源行和事件 ID 仍不变。

```json
{
  "version": 1,
  "method": "independent_source_read",
  "review_note": "说明第二次如何从原图复读及怎样解决差异",
  "unresolved": [],
  "sources": [{"id": "src1", "path": "original.png"}],
  "systems": [{
    "id": "src1-row1", "source_id": "src1", "source_row": 1,
    "events": [{"id": "src1-row1-t0", "time": 0, "notes": ["6", "4"], "rapid_to_next": false}]
  }],
  "regressions": [{
    "id": "opening-chord",
    "checks": [{"event_id": "src1-row1-t0", "notes": ["6", "4"], "time": 0}]
  }]
}
```

- manifest 的 `systems[].source_system_id` 对应账本行 ID，事件 `source_event_id` 对应账本事件 ID。
- 账本 `time` 是一整行的整数时间；manifest 中等于 `小节索引 × slots_per_measure + slot`，不是截图像素。
- 完整比较音符多重集（含音高点）、时间和 `rapid_to_next`，每个来源事件必须恰好使用一次。
- `audit.regression_checks` 中的每个名称都必须对应账本中的可执行 `checks`，不能只写“已通过”。已知错例必须具有实际断言。
- 缺原图、未解决疑点、来源事件缺失／重复、任一音符或关系不匹配都会阻止最终渲染。旧清单先补真实复核记录，不得为兼容而取消检查。

## 《诀别书》回归样例

这些样例适用于用户提供的三页版本；不能套用到同名曲的其他编配。

- P1 第一、三行开头只有 `6、4` 同按，没有 `1`。
- P1 第二行右半快速 `2' 3' 2' 3' 2'` 的 `5、3` 配最后一个 `2'`，不是第三个音。
- P2 第三行旋律相对第一行高一个八度，含 `1''`；伴奏不随之整体升八度。
- P2 第四行最后一次同按只有 `6、3、1`，无附加 `6'`，位于右半的第 8 时间单位。
- P3 第一、三行左半 `3' 3' 3'` 的伴奏 `4` 配第三音；第二、四行 `2' 2' 2'` 的伴奏 `3` 也配第三音。
- P3 第二行左半随后两个 `7` 都无音高点。

修改校验器后执行 `node --test tests/*.test.mjs`，确认正常清单通过、错八度、错配伴奏、漏音、改时间、漏横线及伪回归标记均被拒绝。

全谱时间轴校验在来源比较后执行。即使两份记录在小节末一起误填 false，仍会按经原图确认的槽位检测漏连；它不会证明槽位本身读对，不能替代原图复读。默认不做 SHA256／哈希校验。局部修订可复用已保存的真实复核账本，仅复读变动处与前后相邻事件；没有旧账本时必须从原图恢复，不允许从待验数据生成同源副本。
